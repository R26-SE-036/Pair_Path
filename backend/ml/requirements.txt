# What the SERVICE needs to answer a request. Nothing else.

# Pinned (L15). Versions match the environment the current artifacts were
# built and tested with - bump deliberately, never silently.
#
# ===================== WHY THIS FILE GOT SMALLER =====================
# The image was 1.2GB. Measured inside it, the largest directories were:
#
#     nvidia   454MB      CUDA runtime, pulled in by xgboost
#     xgboost  228MB
#     scipy    139MB
#     pandas    73MB
#     numpy     69MB
#     sklearn   47MB
#
# Half the image was CUDA. The `xgboost` wheel on PyPI bundles GPU support by
# default, and this service runs inference on a CPU container - it loads a
# serialized booster and calls predict_proba. `xgboost-cpu` is the same
# library at the same version built without the GPU bits.
#
# pandas, pymongo, httpx, python-dotenv and python-multipart were also in
# here. pandas belongs to dev_tools; the other four are used by NOTHING in
# this repository - pymongo was for a Mongo export script that no longer
# exists, and python-multipart is only needed for form uploads, which this
# JSON-only service does not accept.
# =====================================================================
