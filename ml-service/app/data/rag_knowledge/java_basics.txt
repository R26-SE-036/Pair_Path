Tags: basics, variables, declaration, scope
Keywords: variable, declare, scope, undefined, cannot find symbol
Content: A variable exists only inside the block of braces where it was declared. Declaring it inside a loop or an if statement means it disappears when that block ends, which is why it can appear undefined a few lines later.
Example: Find where your variable is declared and trace the braces around it to see how far it reaches.

Tags: basics, syntax, semicolon, braces
Keywords: semicolon, brace, bracket, parenthesis, syntax, expected
Content: Java statements end with a semicolon and blocks are enclosed in braces. A missing or extra one changes where a statement or block is considered to end, which can move code inside or outside a loop without any visible sign.
Example: Check that the braces around the block you are working on open and close where you intend, and that each statement ends properly.
Question: Does each block start and finish exactly where you meant it to?

Keywords: string, text, equals, concatenate, compare, char
Content: Strings in Java are objects, not simple values, so comparing them with the equality operator asks whether they are the same object rather than whether they contain the same characters. Two strings can look identical on screen and still fail that comparison.
Example: Count the characters in each string, including spaces at either end, and compare the two counts.
