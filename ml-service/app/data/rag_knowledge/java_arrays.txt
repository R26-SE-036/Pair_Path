Content: Java arrays are zero-indexed. An array holding N elements has valid positions 0 through N-1, so the highest index you can read is one less than the length. Reaching for position N or beyond throws an ArrayIndexOutOfBoundsException.

Tags: arrays, length, size, capacity
Keywords: length, size, capacity, empty, array
Content: An array's length is fixed when it is created and never changes afterwards. The length property tells you how many slots exist, not how many hold meaningful values. An array can be full-size and still contain defaults you never assigned.
Example: Print the array's length alongside the values it holds, and check whether every slot was actually given a value.
